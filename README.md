## Objetivo 
Projeto desenvolvido para demonstrar controle de versão, conteinerização, execução com Docker Compose e provisionamento de infraestrutura com Terraform. 
 
## Tecnologias utilizadas 
- Git 
- GitHub 
- Docker 
- Docker Compose 
- Terraform 
- Nginx 
 
#Executar a aplicacao
```bash
docker compose up -d
```
Acesse:
http://localhost:8080

Para encerrar:

```bash
docker compose down
```
